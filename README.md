## Getting Started

### Prerequisites

Before you begin, make sure you have the following installed:

- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rahul-gound/solid-spoon.git
   ```

2. Navigate into the project directory:

   ```bash
   cd solid-spoon
   ```
